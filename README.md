<summary><b>◆ MU-MIMO & SIC — Étude et simulation de la boucle d'annulation successive d'interférences</b></summary>

<br/>

> Modélisation complète d'un système MU-MIMO avec canal de Rayleigh et simulation de la boucle SIC en Python. Comparaison de cinq récepteurs (ZF, MMSE, SIC, SIC-ZF, SIC-MMSE) sur les métriques BER, efficacité spectrale et signal résiduel.

| Attribute | Detail |
|---|---|
| **Stack** | Python · NumPy · Matplotlib · SciPy |
| **Domain** | Wireless Communications · Signal Processing |
| **Detectors** | ZF · MMSE · SIC · SIC-ZF · SIC-MMSE |
| **Key Metrics** | BER vs SNR · Spectral Efficiency · Residual Power |
| **Scope** | 6 simulations · Monte-Carlo · Canal Rayleigh |
| **Repository** | [![GitHub](https://img.shields.io/badge/View-Repository-6D28D9?style=flat-square&logo=github)](https://github.com/otmane-belghiti) |

- Proved SIC-MMSE achieves Shannon's MAC capacity bound analytically and empirically.
- Quantified error propagation cascade: 10% error at iteration 1 degrades all subsequent users.
- Demonstrated decoding order impact: decreasing-power order is systematically optimal.
